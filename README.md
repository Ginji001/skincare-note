# スキンケア・ノート

化粧品の登録と、曜日ごとの朝・夜ルーティンを管理する無料のPWAです。

- ログイン不要。データは使っている端末のブラウザ内だけに保存され、サーバーには送信しません
- ホーム画面に追加するとアプリとして使え、オフラインでも動きます
- 製品は写真から製品名・全成分を読み取って登録できます（読み取りは端末内で実行）
- 全成分から成分の目印（ビタミンA系・酸・ビタミンC・ナイアシンアミド・香料など）を付け、同じ時間帯の重なりや刺激が出やすいとされる組み合わせを表示します（医療的な判断ではありません）
- 「肌が敏感な日」に切り替えると、「刺激が強め」にした製品を休む候補として表示します
- 機種変更の前は「設定」→「バックアップを書き出す」で保存してください

文字認識に Tesseract.js 7.0.0（Apache-2.0）を vendor/ocr に同梱しています。
